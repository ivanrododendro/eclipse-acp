Eclipse ACP Connector

Update Site

This is the p2 update site for Eclipse ACP Connector, an Eclipse IDE client for the Agent Client Protocol (ACP). Eclipse uses the files in this directory to install and update the connector.

Install in Eclipse

  1. Open Help → Install New Software….
  2. Choose Add… and use this update-site address:
https://ivanrododendro.github.io/eclipse-acp/
  1. Select Eclipse ACP Connector and complete the installation wizard.
Requires Eclipse IDE 2026-06 or newer and Java 21. Learn more in the project repository.
